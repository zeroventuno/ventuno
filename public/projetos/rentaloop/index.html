Rentaloop

Aluguel de bicicletas de alta performance de ponta a ponta: reserva online, pagamento, contrato pronto para assinar e a frota bloqueada pela janela real de transporte.

Sistema de gestão de aluguel de bicicletas de alta performance, rodando numa operação real na Itália.
Problema
Cada bicicleta é um ativo caro e único, montada peça a peça, que precisa estar no lugar certo, no tamanho certo, para o cliente certo. E o mesmo equipamento é disputado por reservas que se sobrepõem no transporte, não só no calendário — planilha não resolve isso.
Modelo
A bicicleta é tratada como ativo, com componentes, custo de montagem e retorno acumulado em aluguéis. Um diagrama interativo com pontos clicáveis liga cada peça ao campo do formulário — cadastrar deixa de exigir vocabulário técnico de mecânico.
Janela física
Um aluguel de segunda a sexta pode ter a bike saindo no domingo e voltando no sábado. Bloquear a frota pelas datas contratadas faz duas reservas colidirem no caminhão, então entrega e devolução são campos próprios e o bloqueio usa a janela real de indisponibilidade.
Contrato
O contrato de locação não é texto decorativo: tem cláusulas de responsabilidade, condições de pagamento, dados bancários e política de cancelamento com penalidades. É montado a partir dos dados do aluguel, no idioma do cliente, pronto para assinar.
Migração
O projeto atravessou três bancos e uma reescrita completa de framework, sempre com dados reais em produção. As três tabelas centrais nunca foram recriadas: as 27 migrations só estendem o schema, e a reescrita foi erguida sobre o mesmo banco — o que permitiu migrar módulo a módulo em vez de virar a chave de uma vez.
Em andamento · de sistema a produto

Uma camada de marca em vez de um fork

A identidade visual e a identidade jurídica foram extraídas para uma camada única: cores, nome, favicon e os dados que entram no contrato saem todos de um só lugar. É o que transforma um sistema feito para um cliente em base para atender vários — sem duplicar código e sem manter dois sistemas parecidos vivos ao mesmo tempo.
